# Manual corto — Líderes de servicio (HGP)

## 1. Abrir el sistema
Entre con su usuario (selector «Entrar como»). Use **Líder de servicio** para elaborar.

## 2. Configurar el mes
- Elija **Enfermería** o **Médico**
- Mes, año y **servicio**
- Nombre del jefe / líder

## 3. Cargar personal
1. Pestaña **PERSONAL**
2. «Descargar plantilla» → complete FUN, nombres, relación laboral, código, sección
3. «Importar Excel/CSV»
4. «Cargar al horario»

También puede agregar filas con «+ Agregar personal» en HORARIO.

## 4. Pintar turnos
1. Elija una **clave** (D1, N1, CE, X, L, V…)
2. Active **Pintar**
3. Clic en el día → asigna; clic otra vez en la misma clave → quita; clic derecho → borra

## 5. Controles útiles
- **Limpiar mes**: borra solo celdas
- **Duplicar mes anterior**: copia del horario guardado del mes previo (mismo servicio)
- **Autocompletar feriados**: marca **F** en celdas vacías

## 6. Revisar cobertura
Pestaña **DISTRIBUCIÓN**: días en rojo tienen personal bajo el mínimo configurado.

Si hay vacaciones/permisos (médico), complete **CONTINGENCIA**.

## 7. Guardar y enviar
1. **Guardar**
2. **Enviar a revisión**
3. Dirección / TH **Aprueba** → el cuadro queda bloqueado
4. **Exportar Excel** o **Imprimir / PDF** para archivo
