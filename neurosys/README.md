# NeuroSys ERP

Base inicial del ERP clínico para el Centro Neuroterapéutico Integral Ñampi
Wasi. Esta primera iteración establece el lenguaje visual, la navegación
principal y un dashboard ejecutivo adaptable a escritorio y dispositivos
móviles.

## Tecnologías

- Next.js con App Router
- React y TypeScript
- Tailwind CSS
- Lucide Icons

## Desarrollo

Desde el directorio `neurosys`:

```sh
npm install
npm run dev
```

La información visible actualmente es demostrativa. Los módulos clínicos se
conectarán posteriormente a persistencia, autenticación y políticas de acceso
por organización, sede y rol.
